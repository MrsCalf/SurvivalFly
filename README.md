# SurvivalFly

**English** · [简体中文](#简体中文)

A lightweight Fabric mod for **Minecraft: Java Edition 26.2** that grants temporary flight permission in Survival mode without switching game mode. Use `/fly` to take off, land to lose flight automatically, or `/defly` to revoke it manually.

## Features

- **Survival-friendly flight** — grants `mayfly` in Survival/Adventure without changing game mode.
- **Auto-revoke on landing** — your permission is automatically removed when you actually touch the ground after flying (toggleable).
- **Manual revoke** — `/defly` removes flight permission at any time.
- **Hotkeys** — configured hotkeys to trigger `/fly` and `/defly` without opening chat.
- **In-game settings panel** — rebind any hotkey (single key or two-key combo, including the panel hotkey itself) and toggle landing auto-revoke.
- **Mod Menu integration** — open the settings panel from Mod Menu's config button.
- **13 languages** out of the box.

## Commands

| Command | Description |
|---|---|
| `/fly`   | Grants flight permission (Survival/Adventure only). |
| `/defly` | Manually revokes flight permission. |

## Default Hotkeys

| Action | Default |
|---|---|
| `/fly` | `F7` |
| `/defly` | `F9` |
| Open settings panel | `F7` + `F9` |

## Compatibility

- Minecraft: Java Edition 26.2
- Fabric Loader ≥ 0.19.3
- Fabric API (required)
- Mod Menu ≥ 20.0.1 (optional, for the Mod Menu config entry)
- Java ≥ 25

# 简体中文

一款轻量级的 Minecraft Java 版 Fabric 模组，让你在不切换游戏模式的情况下获得 **临时飞行权限**。输入 `/fly` 起飞，落地后自动撤销飞行权限，或使用 `/defly` 手动撤销。

## 功能特性

- **生存模式飞行** — 在生存/冒险模式中直接获得飞行权限，无需切换创造模式。
- **落地自动撤销** — 真正落地后自动撤销飞行权限（可在设置中关闭）。
- **手动撤销** — `/defly` 可随时撤销飞行权限。
- **快捷键支持** — 用配置的快捷键一键触发 `/fly` 或 `/defly`，无需打开聊天框。
- **游戏内设置面板** — 可自定义全部快捷键（支持单键或两键组合，包括面板本身的快捷键），并可切换落地自动撤销。
- **Mod Menu 集成** — 在 Mod Menu 的配置按钮中直接打开设置面板。
- **内置 13 种语言翻译**。

## 指令

| 指令 | 说明 |
|---|---|
| `/fly`   | 获得飞行权限（仅生存/冒险模式）。 |
| `/defly` | 手动撤销飞行权限。 |
